# FitLife – Fitness & Healthy Lifestyle Blog

A responsive HTML/CSS/JavaScript blog website suitable for GitHub Pages.

## Features
- Responsive professional design
- Home, Blog, About and Contact pages
- Four SEO-friendly sample articles
- Mobile navigation
- Front-end contact form demo
- No backend/database required

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Upload all files while keeping the folder structure unchanged. Set GitHub Pages to deploy from the branch/folder containing `index.html`.
